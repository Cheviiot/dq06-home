## Обновления

Откройте **Настройки → Обновления → Приложения и обновления**. Кнопка **Проверить обновления** запускает проверку в Obtainium. Для смены источников выберите **Загрузить источники**, затем **Импортировать**. В 12.16.6 эти кнопки называются «Обновить список» и «Применить». Публичный профиль содержит Sever TV, Настройки Sever, Lift и DQ06 Files. APK лаунчера и файлового менеджера обновляются через GitHub-релизы и Obtainium; подпись каждого APK должна совпадать с установленной. YouTube обновляется через Google Play, RuStore сохраняет собственный механизм обновлений.

Профиль загружается по кнопке. Импорт обновляет перечисленные записи Obtainium и не удаляет отсутствующие в JSON приложения. Для установки обновлений Android может запросить подтверждение.

## Linux Lite

Для терминала и управления Linux нужна системная служба DQ06 Clean 12.16.6. Debian ARMhf входит в прошивку. SSH запускается при загрузке и принимает ключи.

## Совместимость и лицензии

Android 8.0 и новее. На Athena проверены статус Wi-Fi, управление привязкой штатного пульта, терминал Debian и запуск SSH после перезагрузки.

Репозиторий содержит лицензию CleanYourTV MIT, лицензию шрифта Outfit OFL, атрибуцию Fluent Emoji и лицензию Apache-2.0 библиотек встроенного терминала (`terminal-emulator` и `terminal-view`). Приложение Termux не требуется.
